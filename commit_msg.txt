🧪 [testing improvement] Add tests for Chat component error handling

🎯 **What:** The testing gap addressed
The previous codebase lacked testing for the complex `getUserMedia` error path within the `WebSocket` `onmessage` event listener in `src/pages/Chat.tsx`.

📊 **Coverage:** What scenarios are now tested
This change adds test coverage in `src/pages/Chat.test.tsx` verifying that when a user denies microphone access during a call sequence (i.e. `navigator.mediaDevices.getUserMedia` throws an error):
- The error is accurately caught and logged via `console.error`.
- The call state is correctly cleaned up by validating that the UI returns to displaying the "Call Agent" button.

✨ **Result:** The improvement in test coverage
We've significantly increased confidence in the audio call functionality by establishing test coverage for critical media permission failures, improving reliability and averting unhandled exceptions.
